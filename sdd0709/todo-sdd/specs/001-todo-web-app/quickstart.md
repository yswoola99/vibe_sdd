# 빠른 시작 가이드: 오늘의 할 일 웹 앱

## 사전 준비

- Python 3.11+
- 가상 환경 생성 및 의존성 설치
- .env 파일에 DATABASE_URL 설정

## 실행 절차

1. 가상 환경을 생성하고 의존성을 설치한다.
2. .env 파일을 작성해 SQLite 경로를 설정한다.
3. FastAPI 앱을 실행한다.
4. 브라우저에서 메인 화면에 접속해 기능을 확인한다.

## 검증 시나리오

- 새 할 일을 추가하고 목록에 표시되는지 확인한다.
- 완료 토글이 정상 동작하는지 확인한다.
- 삭제 전 확인 절차가 동작하는지 확인한다.
- 필터와 남은 개수 갱신이 즉시 반영되는지 확인한다.
- 새로고침 후에도 목록이 유지되는지 확인한다.
- 모바일 화면(360px)에서 주요 요소가 보이는지 확인한다.
