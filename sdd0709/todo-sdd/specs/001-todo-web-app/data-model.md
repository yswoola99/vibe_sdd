# 데이터 모델 문서: 오늘의 할 일 웹 앱

## 엔티티

### Todo

| 필드 | 타입 | 설명 | 제약 조건 |
|---|---|---|---|
| id | integer | 할 일의 고유 식별자 | 자동 증가, PK |
| title | string | 할 일 제목 | 필수, 공백 불가 |
| completed | boolean | 완료 여부 | 기본값 false |
| created_at | datetime | 생성 시각 | 자동 기록 |
| updated_at | datetime | 수정 시각 | 자동 갱신 |

## 관계

- 한 개의 할 일 항목은 독립적으로 존재하며, 다른 엔티티와의 관계는 없다.
- 목록 화면은 Todo 엔티티 집합을 필터 조건으로 조회한다.

## 상태 전이

- 생성: `incomplete` 상태로 생성된다.
- 완료 토글: `completed=false` → `completed=true` 또는 그 반대로 변경된다.
- 삭제: 엔티티가 제거된다.

## 검증 규칙

- 제목은 비어 있거나 공백만으로 구성될 수 없다.
- 완료 상태는 boolean 값이어야 한다.
- 삭제 요청 시 존재하지 않는 ID는 404로 처리한다.
